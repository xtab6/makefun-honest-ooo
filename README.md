One painfully honest out-of-office auto-reply: away until Monday, too tired to do your email justice, and promising a proper reply next week instead of a bad one today — honest enough to sting, polite enough to keep.

## Run it

```sh
python3 main.py
```

Writes the reply to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
